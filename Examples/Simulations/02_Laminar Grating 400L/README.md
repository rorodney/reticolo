# Laminar Grating 400 l/mm

Physical 400 l/mm laminar (trapezoidal) grating measured at HZB/ELISA. Compare against `../../Reference_Data/HORIBA_ELISA_Experimental/`.

Geometry: depth 14.9 nm, sidewall 15°, groove/period 0.67. Stack: 29 nm Pt + optional 1 nm C on Si (uncomment the `add_layer` call for C to enable contamination).

Result sets in `Results/`:
- `15deg_TE` — TE, α = 15°, clean
- `15deg_TM_non_contaminated` — TM, α = 15°, clean
- `15eg_TM_Contaminated` — TM, α = 15°, contaminated
- `75deg_TM_Contaminated` — TM, α = 75°, contaminated
